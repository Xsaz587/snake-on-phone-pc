# NEON//SNAKE

Локальная multiplayer-база игроков для игры на HTML Canvas. Сервер не требует внешних Python-пакетов.

## Запуск с ngrok

В PowerShell из этой папки:

```powershell
python server.py
```

Во втором окне PowerShell:

```powershell
ngrok http 8000
```

Откройте HTTPS-адрес, который покажет ngrok. Сайт и API работают через один адрес, поэтому отдельную настройку URL во фронтенде делать не нужно.

## Данные игроков

После создания игрока сервер создаёт:

```text
data/
  players.db
  players/<player-id>/
    player.db
    inventory.json
```

`player.db` хранит профиль, а `inventory.json` содержит открытые и экипированные образы.

Публичный ngrok-адрес не имеет авторизации: любой, у кого есть ссылка, сможет создавать игроков и видеть рейтинг. Для настоящего публичного сервера нужно добавить авторизацию и ограничить CORS.

## Арены и лобби

Нажмите `Арена` в верхней панели:

1. Создатель нажимает `Создать арену` и отправляет друзьям шестизначный код.
2. Остальные вводят код и нажимают `Войти`.
3. Каждый участник нажимает `Готово`.
4. Кнопка `Начать матч` появляется у создателя только после готовности всех участников.

Состояние лобби обновляется автоматически. Арены хранятся в памяти запущенного сервера и очищаются после его перезапуска.
